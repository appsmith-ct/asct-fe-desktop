# src-tauri (placeholder)

The Tauri v2 desktop shell is added in milestone M8, once the engine and UI are both complete enough to
package (see `asct-app/docs/specs/` for the milestone list). Until then the UI runs as a local web app:
`appsmith serve` for the engine, `pnpm dev` for the UI, pointed at each other over `localhost`.

This directory is a placeholder so the repository layout matches the spec ahead of time; it will be
replaced by `tauri init` output in M8.
